= OpenShift 살펴보기
:navtitle: OpenShift 살펴보기

include::vars.adoc[]

OpenShift는 플랫폼과 상호작용하기 위한 두 가지 주요 인터페이스를 제공합니다: 시각적 관리를 위한 웹 기반 콘솔과 스크립팅 및 고급 작업을 위한 명령줄 인터페이스입니다. 이 섹션에서는 두 도구에 접근하고 효과적으로 사용하는 방법을 배웁니다.

[#the_web_console]
== 웹 콘솔

OpenShift 콘솔은 Project, 애플리케이션, 클러스터 리소스를 관리할 수 있는 직관적인 그래픽 인터페이스를 제공합니다. 최신 웹 브라우저에서 접근할 수 있으며, 일반적인 관리 및 개발 작업을 간소화하도록 설계되었습니다.

=== OpenShift 웹 콘솔 접속하기

[.bordershadow]
image::openshift-console-login.png[OpenShift 웹 콘솔 로그인 화면,width=500,link="self",window=_blank]

OpenShift 콘솔에 접속하려면 이 페이지 오른쪽의 **OCP Console** 탭을 클릭한 후 제공된 자격 증명으로 로그인합니다.

[.bordershadow]
TIP: 모니터 화면이 작아서 불편한 경우, 오른쪽 상단의 'Tabs'를 누르면 가이드 문서가 접히고 웹콘솔 화면만 볼 수 있습니다. 그리고 다시 Instruction이나 Split를 누르면 가이드 문서를 다시 볼 수 있습니다.

**사용자 이름:** ``{user}``

**비밀번호:** ``{ocp4_starter_password}``

새 브라우저 탭에서 열고 싶다면: link:{ocp4_starter_console_url}[{ocp4_starter_console_url}^]

로그인하면 Project를 확인하고 플랫폼의 기능을 탐색할 수 있는 기본 대시보드가 표시됩니다.

[.bordershadow]
image::openshift-console-dashboard.png[로그인 후 표시되는 OpenShift 웹 콘솔 기본 대시보드,link="self",window=_blank]

[#command_line_interface]
== 명령줄 인터페이스

웹 콘솔이 시각적 관리에 훌륭한 도구이긴 하지만, OpenShift CLI(``oc``)는 자동화 기능과 고급 기능에 대한 접근을 제공합니다. 이 CLI는 Go로 작성된 단일 실행 파일이며 Microsoft Windows, macOS, Linux에서 사용할 수 있습니다.

=== CLI 설치 확인하기

CLI는 워크숍 환경에 미리 설치되어 있습니다. 오른쪽에서 Terminal 탭을 눌러 사용 가능한지 확인하고 버전을 확인해 보세요.

[source,bash,role="copypaste",subs="attributes"]
----
oc version
----

다음과 유사한 출력이 표시됩니다:

[.console-output]
[source,subs="attributes"]
----
Client Version: {ocp4_starter_cli_version}
Kustomize Version: v5.6.0
Kubernetes Version: v1.33.x
----

=== CLI로 로그인하기

명령줄을 사용하여 OpenShift 클러스터에 인증합니다:

[source,bash,role="copypaste",subs="attributes"]
----
{ocp4_starter_login}
----

이 명령은 사용자 이름과 비밀번호를 사용하여 클러스터에 인증합니다. ``Use insecure connections? (y/n):`` 라는 메시지가 뜨면 y를 입력하세요.

NOTE: "The server uses a certificate signed by an unknown authority."라는 메시지가 표시되어도 이 워크숍 환경에서는 무시해도 됩니다.
이는 클러스터의 API 인증서가 자체 서명(self-signed)되었음을 나타내며, 개발 및 테스트 환경에서는 흔한 경우입니다.

[.bordershadow]

TIP: 또는 토큰을 사용하여 인증할 수도 있습니다. 토큰을 얻으려면 아래와 같이 OpenShift 웹 콘솔에서 **Copy login command** 옵션을 사용하세요.

[.bordershadow]
image::openshift-console-login-command.png[웹 콘솔의 Copy login command 옵션 화면,link="self",window=_blank]

=== 접근 권한 확인하기

인증이 제대로 되었는지, 그리고 할당된 리소스에 접근할 수 있는지 확인해 보겠습니다.

먼저 로그인 자격 증명을 확인합니다:
[source,bash,role="copypaste",subs="attributes"]
----
oc whoami
----

사용자 이름이 표시됩니다:

[.console-output]
[source,subs="attributes"]
----
{ocp4_starter_username}
----

다음으로 나에게 할당된 Project를 볼 수 있는지 확인합니다.
다음 명령어는 현재 내가 접근할 수 있는 모든 project들의 목록을 확인합니다.
[source,bash,role="copypaste",subs="attributes"]
----
oc projects
----

다음과 유사한 출력이 표시됩니다:

[.console-output]
[source,subs="attributes"]
----
You have one project on this server: "Workspace ({ocp4_starter_project})".

Using project "{ocp4_starter_project}" on server "{ocp4_starter_api_url}".
----

훌륭합니다! 이제 웹 콘솔과 명령줄 인터페이스 모두를 통해 OpenShift에 접근할 수 있게 되었습니다. 다음 섹션에서는 이 도구들을 사용하여 플랫폼에서 애플리케이션을 배포하고 관리합니다.
