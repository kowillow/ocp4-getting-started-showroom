== 개요

이 워크샵은 개발자의 관점에서 OpenShift를 실습 중심으로 소개합니다. 실제로 손으로 해보는 대화형 실습을 통해, OpenShift 플랫폼에서 컨테이너화된 애플리케이션을 빌드하고 배포하고 관리하는 방법을 배웁니다.

== 배우게 될 내용

**OpenShift 시작하기:**

* OpenShift 명령줄 클라이언트와 웹 콘솔 사용하기
* OpenShift 개발자 인터페이스를 살펴보고 핵심 개념 이해하기

**애플리케이션 배포와 관리:**

* 기존 컨테이너 이미지를 사용하여 애플리케이션 배포하기
* Git 저장소의 소스 코드로부터 직접 애플리케이션 배포하기
* 레이블을 사용하여 구성 요소를 식별하고 정리하기
* 다양한 트래픽 부하를 처리하도록 애플리케이션 스케일링하기
* 무중단으로 애플리케이션을 업데이트하고, 문제 발생 시 이전 버전으로 롤백하기

**네트워킹과 접근:**

* Route를 통해 애플리케이션을 외부 사용자에게 노출하기
* 애플리케이션 네트워킹과 서비스 디스커버리 구성하기
* OpenShift Route와 Kubernetes Ingress의 차이 이해하기

**데이터베이스 연동:**

* OpenShift 서비스 카탈로그에서 데이터베이스 배포하기
* 데이터베이스에 연결하여 사용하도록 애플리케이션 구성하기

**설정과 상태 관리:**

* ConfigMap과 Secret으로 애플리케이션 설정을 코드와 분리하기
* StatefulSet으로 안정적인 네트워크 식별자와 저장소가 필요한 워크로드 배포하기
* Requests/Limits와 ResourceQuota로 컨테이너와 프로젝트의 자원 사용량 관리하기
* nodeSelector와 Pod Anti-Affinity로 Pod가 배치되는 노드를 제어하기

**협업과 자동화:**

* 코드 변경 시 자동으로 애플리케이션이 빌드되도록 webhook 설정하기
* Job과 CronJob으로 일회성 작업과 예약 작업을 자동화하기

NOTE: 이 워크샵은 Java 애플리케이션을 사용하지만, 여기서 다루는 개념과 기법은 .NET, Node.js, Python 등 다른 런타임으로 빌드된 애플리케이션에도 동일하게 적용됩니다.
