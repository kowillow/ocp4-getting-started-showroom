이 워크숍은 퍼블릭 클라우드에서 실행되는 OpenShift 환경에서 호스팅됩니다. 이 환경은 다음과 같은 시스템으로 구성됩니다:

* Control Plane 노드
* Worker 노드(또는 "애플리케이션" 노드)
* 동적 프로비저닝 스토리지
* 프라이빗 컨테이너 레지스트리
* 라우팅 레이어
